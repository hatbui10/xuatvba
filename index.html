Cách dùng & cấu trúc file CSV

1️⃣ Tải file lênChọn hoặc kéo thả một/nhiều file .xlsm. Công cụ giải nén vbaProject.bin, đọc cấu trúc OLE/CFB và stream dir để lấy đúng vị trí mã của từng module.
2️⃣ Kiểm tra kết quảXem danh sách module, số dòng và xem trước mã nguồn ngay trên trang trước khi tải xuống.
3️⃣ Tải CSVCSV có các cột: File nguồn, Module, Loại module, Stream, Dòng (số thứ tự dòng), Mã VBA. File có dấu BOM UTF-8 nên mở bằng Excel không lỗi font tiếng Việt.
Kỹ thuật: ZIP → xl/vbaProject.bin → OLE Compound File (MS-CFB) → giải nén MS-OVBA (RLE) → mã nguồn VBA → CSV. Mọi thao tác chạy cục bộ bằng JavaScript trong trình duyệt của bạn; không có dữ liệu nào rời khỏi máy. Nên dùng Chrome / Edge / Firefox / Safari bản mới (cần API giải nén DecompressionStream). File Excel có mật khẩu mã hóa (Encrypt with Password) sẽ không đọc được.
